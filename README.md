# EquilibraMind 🌿

**Tu bienestar también merece espacio.**

Plataforma web responsive para prevención del agotamiento laboral (burnout), promoción del bienestar psicológico y acompañamiento a personas y empresas.

Este repositorio contiene la evolución de un **prototipo académico con proyección comercial**, basado en el proyecto EquilibraMind de Psicología Organizacional.

## Objetivos del primer prototipo

- Landing page de marca humana, profesional y accesible.
- Experiencias de demostración para personas y empresas.
- Chequeo educativo de bienestar que **no es un diagnóstico**.
- Profesionales, agenda, reserva y planes **ficticios**, sin cobros reales.
- Diseño adaptable a móviles y arquitectura preparada para evolucionar.

## Aviso importante

**Demostración académica:** las identidades, citas y métricas usadas en el prototipo son ficticias. No se prestan servicios clínicos reales ni se recopilan historias clínicas. Para operar comercialmente se requerirán profesionales habilitados, consentimiento informado, política de datos personales y cumplimiento de la regulación colombiana aplicable.

## Despliegue

El sitio se desplegará con Netlify o Vercel. No subir credenciales ni secretos a GitHub.
